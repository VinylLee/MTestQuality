# Roadmap

本文件保留项目的后续方向。四数据集接入、四个固定版本 NLI auditor 和 Conservative Consensus V1 逐条过滤已实现，当前实现与验收依据见 [ensemble 实施方案](MULTI_DATASET_ENSEMBLE_FILTERING_PLAN.md)。下列更广泛的模型类型与组合筛选仍属于未来工作。

## 1. 多测试数据集审计

- 将其他 NLI 测试数据集的增强结果统一为当前最小输入契约。
- 记录各数据集自身的标签映射、来源、增强方法和哈希。
- 在跨数据集汇总时同时保留总体指标与数据集内分组指标，避免大数据集掩盖小数据集问题。

## 2. 第二类模型交叉审计

- 引入与当前 discriminative cross-encoder 不同的第二类审计模型。
- 固定模型 revision、提示词或解码参数，完整记录每个审计器的独立输出。
- 区分“双模型一致”“仅模型 A 一致”“仅模型 B 一致”“双模型均不一致”，再做人审抽样估计各组精度。

## 3. 筛选功能

- 支持按数据集、label、MR、source 状态、置信度、margin、熵和多模型一致状态组合筛选。
- 后续划分训练/验证/测试集时按 `pair_id` 原子化切分，避免 source/增强变体跨 split；当前质量过滤按增强记录逐条决策，不连带删除其他变体。
- 支持目标 label/MR 配比和固定随机种子。
- 输出筛选配置、输入/输出哈希、保留/剔除原因和分组覆盖率，确保可复核。

## 原则

- 单一模型的 softmax confidence 不作为人工金标。
- 当前保守规则使用 source gating、同向高置信共识和 gold blocker；不引入人工标注流程。
- 不覆盖原始输入；所有结果写到独立输出目录。
